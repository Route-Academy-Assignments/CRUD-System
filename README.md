# CRUD System

A basic implementation of a Create, Read, Update, and Delete system using vanilla JavaScript.

## ✨ Features
- **Create:** Add new items to a list.
- **Read:** Display all items in a table or list.
- **Update:** Edit existing items.
- **Delete:** Remove items from the list.

## 🛠️ Tech Stack
- **Front-End:** JavaScript, HTML, CSS

## 🚀 How to Use
1. Clone this repository.
2. Open `index.html` in your browser.
3. Use the form to add, edit, or delete items.
